- **koan-kit-web 0.9.** The page loads no script of its own any more: the magnet rows are the kit's `RepeatField`, a log line's time is its `Time`, and its sheets keep above an on-screen keyboard by themselves, so `web/`, the bundle and its build are gone. A paste of several lines now fills a row for each, magnet or not, where the old script kept only `magnet:` links; `/add` names any row that is not one. The add sheet reads its body from the server each time it opens and is closed by the server once a batch goes in whole. The kit's `Navigation` owns the history, so Back and Forward load the page in place. A request answered with an error status, which Datastar would otherwise drop silently, is said over the page, a lost connection is said once Datastar stops retrying, and an ended session goes to sign-in. The destination listing is covered while the next folder is read, and a download's piece count and size and its info hash are labelled rows of its readings.
