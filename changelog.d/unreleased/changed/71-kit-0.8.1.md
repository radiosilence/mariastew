- **koan-kit-web 0.8.1.** The kit's `Navigation` owns the history in place of `askama_datastar::history`, so Back and Forward load the page in place. A request answered with an error status, which Datastar would otherwise drop silently, is said over the page, a lost connection is said once Datastar stops retrying, and an ended session goes to sign-in. The destination listing is covered while the next folder is read, a download's piece size and info hash are labelled rows of its readings, and the stream's fingerprints no longer strip busy-signal names, since the kit now names them by what each control is.
